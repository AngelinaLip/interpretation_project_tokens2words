# interpretation_project_tokens2words
Исследование процесса внутренней детокенизации (sub-word detokenization) и существования внутреннего лексикона (inner lexicon) в современных больших языковых моделях на материале русского языка на материале статьи ICLR 2025 «From Tokens to Words: On the Inner Lexicon of LLMs»
